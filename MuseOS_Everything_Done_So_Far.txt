MuseOS — EVERYTHING DONE SO FAR

1. PROJECT IDEA

Project name:
MuseOS

Full title:
MuseOS — Integrated DBMS & Operating Systems Project

The project combines DBMS + Operating Systems into one C++ application.

The application uses a music library as the practical domain.

Important idea:
Music is the application domain. The project itself demonstrates DBMS and OS concepts.

We are NOT building an actual operating system. We are building an application that simulates OS concepts while using a real database.

10. IMPORTANT SQLITE TERMINAL LESSON

Inside SQLite:

sqlite>

means we are inside SQLite and SQLite is waiting for an SQL command.

If the prompt becomes:

...>

SQLite thinks the previous command is not finished.

This usually happens because:
- a semicolon is missing
- a quote was not closed
- parentheses were not closed

To cancel an unfinished command:

Ctrl + C

Then we return to:

sqlite>


11. IMPORTANT DATABASE FILE LESSON

database/museos.db was accidentally opened directly in VS Code.

It showed unreadable/binary-looking characters.

This is normal.

.db is a binary database file, not a text file.

Do NOT edit museos.db directly in VS Code.

Instead, interact with it through SQLite:

sqlite3 database/museos.db

and SQL commands.

17. GENRES TABLES

Created:

CREATE TABLE Genres (
    genre_id INTEGER PRIMARY KEY,
    name TEXT NOT NULL UNIQUE
);

CREATE TABLE SongGenres (
    song_id INTEGER NOT NULL,
    genre_id INTEGER NOT NULL,
    PRIMARY KEY (song_id, genre_id),
    FOREIGN KEY (song_id) REFERENCES Songs(song_id),
    FOREIGN KEY (genre_id) REFERENCES Genres(genre_id)
);

Relationship:

Songs <---- SongGenres ----> Genres
             many-to-many

A song can have many genres, and a genre can contain many songs.
SongGenres is the junction/link table between them.

Genres currently added:

1 | Alternative R&B
2 | Hip Hop
3 | Rock
4 | Electronic
5 | Pop

SongGenres currently added:

song_id | genre_id
1       | 1
1       | 2

Meaning: Nikes is tagged as Alternative R&B and Hip Hop.

Verification command (JOIN):

SELECT s.title, g.name FROM Songs s
JOIN SongGenres sg ON s.song_id = sg.song_id
JOIN Genres g ON g.genre_id = sg.genre_id;

Output:

Nikes|Alternative R&B
Nikes|Hip Hop
